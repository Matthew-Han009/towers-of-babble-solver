# 바벨 단어 계산기 (Towers of Babble Solver)

손에 든 글자 타일로 만들 수 있는 단어 중, 실제 게임 수치 기준으로 가장 센 타워와 부품을 찾아주는 도구입니다.

- 바로 쓰기: https://sidequest.hcmll0120.workers.dev/apps/towers-of-babble/
- 제작기: https://sidequest.hcmll0120.workers.dev/tools/towers-of-babble/

## 실행

`index.html` 파일 하나로 동작합니다. 내려받아 브라우저로 열면 됩니다. 서버도, 설치도 필요 없습니다.

## 데이터

- 내장 영어 사전과 단어별 게임 수치가 `index.html` 안에 들어 있습니다.
- 단어 분류(명사·동사·형용사·부사)는 WordNet 기준이라 게임의 분류와 다를 수 있습니다.

## 알림

비공식 팬메이드 도구이며, Towers of Babble의 개발사·배급사와 관련이 없습니다. 게임 이름과 상표는 각 권리자의 소유입니다.
